# 적정가치(Fair Value) — Valuation Desk 명세

적정가치는 SMA 수급 분석(SECTION 0~7)과 **분리된 별도 기능**이다. SMA 는 발행된 수치만 읽는다.

```
                    ┌──────────────── Valuation Desk (valuation.py) ────────────────┐
 재무·컨센서스·peer ─►│ prepare ─► 리서치(Claude 세션) ─► publish(검증 → 계산 → 발행) │─► reports/valuation/{T}.json ─► SMA
 SEC 공시·실적·뉴스 ─►│   패키지      사업·성과·계획·뉴스       시나리오 확률가중 DCF      │   reports/tickers/{T}/valuation.html
                    │                → 시나리오 가정        + 기계적 모델 교차검증      │   state/valuation/research/{T}.json
                    └────────────────────────────────────────────────────────────────┘
```

**왜 두 층인가.** 재무제표만 보는 기계적 모델은 사업모델·경영 계획·뉴스·실행력을 읽지 못한다(가동 전 설비, 인수로 왜곡된 과거 마진,
아직 매출이 없는 사업). 그래서 적정가의 **입력**은 애널리스트 리서치가 만들고, **계산**은 결정적 엔진이 한다.

| 층 | 누가 | 무엇을 | 산출물 |
|---|---|---|---|
| 리서치 | Claude 세션 (`docs/VALUATION_RESEARCH.md` 지침, 주간 내러티브와 같은 방식·API 과금 없음) | 10-K/10-Q·실적발표·가이던스·계획·뉴스를 읽고 약세/기본/강세 시나리오(연도별 성장·목표 GAAP 마진·위험·확률)와 신사업 옵션가치를 근거와 함께 작성 | `{T}_research.json` |
| 계산 | `smartmoney/valuation.py` | 시나리오별 10년 DCF → 확률가중 적정가, 범위 = 약세~강세. 기계적 18개 모델은 **교차검증용 기준선**으로 함께 계산 | 전체 평가 결과 |
| 발행 | `smartmoney/valuation_desk.py` | 리서치 검증(출처 6건 이상·확률 합·범위·근거) 통과 시에만 발행 | `reports/valuation/{T}.json` 등 |
| 소비 | SMA 엔진·대시보드 | `read_published()` 로 수치만 읽고 세션 종가로 괴리율·판정 재산정 | 리포트 JSON `valuation` 키 |

- **리서치가 없는 종목은 SMA 에 적정가가 표시되지 않는다.** 기계적 기준선은 상세 페이지에서 '참고'로만 보인다 (`SMA_VALUATION_ALLOW_MECHANICAL=1` 로 변경 가능).
- 리서치는 실적 발표 후 다시 써야 한다. 100일이 지나면 '갱신 필요'로 표시되고 불확실성이 올라간다.
- 재무·주가가 바뀌면 `valuation.py refresh`(워크플로 `valuation-refresh.yml`)가 **같은 리서치 가정**으로 다시 계산해 재발행한다.

```bash
python3 valuation.py prepare MRVL --out WORK      # 리서치 패키지
python3 valuation.py publish MRVL --research WORK/MRVL_research.json [--dry-run]
python3 valuation.py refresh --watchlist          # 재계산·재발행
python3 valuation.py status                       # 발행 현황
python3 tools/test_valuation.py                   # 회귀 테스트 (네트워크 불필요)
```

| 파일 | 역할 |
|---|---|
| `valuation.py` | Valuation Desk CLI |
| `smartmoney/valuation_desk.py` | 패키지 생성 · 리서치 검증 · 발행 · SMA 조회 접점 |
| `smartmoney/valuation.py` | 성격 분류 · 자본비용 · DCF 코어 · 기계적 모델 · 리서치 시나리오 계산 |
| `smartmoney/fundamentals.py` | Yahoo 재무제표·컨센서스·peer, SEC XBRL 수집 → `state/fundamentals/{T}.json` |
| `smartmoney/render_valuation.py` | 상세 페이지 + 요약 카드 |
| `docs/VALUATION_RESEARCH.md` | 리서치 지침 (조사 순서 · 시나리오 규칙 · 결과물 필드) |

## 0. 리서치 기반 적정가 (발행되는 값)

```
시나리오 s ∈ {약세, 기본, 강세}:
  매출 경로  = 리서치가 준 연도별 성장률(3~10년) → 이후 영구성장률로 감쇠
  영업이익률 = 현재 → 리서치 목표 GAAP 마진 (지정 연차에 도달; 적자 기업은 영업 레버리지 경로)
  할인율     = §3 의 WACC (+ 리서치 가감 ±3%p 이내)
  가치_s     = 10년 DCF(영구성장 · EBITDA Exit 평균) → 주주가치 ÷ 주식수  + Σ(옵션 성공확률 × 옵션 주당가치)
적정가 = Σ 확률_s × 가치_s        범위 = [약세 가치, 강세 가치]
```
금융·REIT 는 시나리오별 주당 가치를 리서치가 직접 산출한다(P/B-ROE·초과이익·P/FFO; 방법과 입력값 명시).

불확실성(100 에서 차감): 시나리오 폭(강세−약세)÷적정가 ×35 (최대 −45) · 리서치 확신도(MEDIUM −12, LOW −25) · 성격 가산의 절반 ·
옵션가치가 적정가의 25% 초과 −10 · 리서치 100일 경과 −15 · 기계적 기준선과 2배 이상 차이 −6. 등급·판정 밴드는 §6 과 같다.

### Finbox 원문과의 대조
finbox.com 의 방법론 글(The Finbox Fair Value · Introducing Fair Value Uncertainty · DCF: Growth/EBITDA/Revenue Exit Method ·
How to Choose the Right Stock Valuation Method)을 직접 읽고 대조했다.

| 항목 | Finbox | 여기서는 |
|---|---|---|
| 기본 가정 | 컨센서스가 있으면 그것을 시작값으로. 저자는 "애널리스트 전망을 검토한 뒤 과거 실적·뉴스·수집한 통찰로 성장률을 고친다"고 명시 | 같은 2단 구조 — 컨센서스 기반 기계적 기준선 + 리서치가 근거를 달아 고친 시나리오. 고치는 단계를 사람 대신 리서치 세션이 수행하고, 고친 근거를 출처와 함께 발행 |
| 현금흐름 | NOPAT + D&A − CAPEX − 순운전자본 증가 (각각 매출 대비 비율로 전망) | 기준선은 Sales-to-Capital 재투자. 리서치는 `capex_pct`·`da_pct`·`nwc_pct` 로 Finbox 식 명시적 빌드를 쓸 수 있다 |
| 잔존가치 | 영구성장(Gordon) · EBITDA 배수 · 매출 배수 3종. EBITDA 배수 기본값 = 자사 현재 · 벤치마크 중앙값 · 섹터 중앙값의 평균. 서로의 내재 배수로 교차 점검 | 같은 3종 + 성숙기 이론 배수를 섞고, 배수가 내포한 영구성장률을 검증 체크로 |
| 할인 | WACC 범위(예: ±0.5%p) · 기중 할인 | WACC ±0.75%p · 기중 할인 · 성숙기 수렴 |
| 주주가치 | EV − 차입금 − 비지배지분·기타 부채 − 우선주 − 연금 + 현금·단기투자 | 같은 순서. 연금 등은 `debt_like_liabilities`, 비지배지분의 경제적 몫·운용리스는 리서치 조정 |
| 모델 선택 | 레버리지가 변하면 무차입 DCF, 안정적이면 자기자본 모델(배당성향 80~110% 면 DDM, 아니면 RI·레버드 DCF). 성장 단계로 예측 기간(안정/5년/10년). 상대가치는 항상 병행 | 성격 분류로 모델·기간 가중치 결정. DDM 은 배당성향 80~110% 일 때 신뢰도 1, 그 밖은 감점 |
| 통합 | 검증을 통과한 모델의 **단순 평균** (사용자가 모델을 켜고 끌 수 있음) | 성격별 가중 × 신뢰도, 이상치 축소 — 발행값은 리서치 시나리오 확률가중 |
| 불확실성 | **모델 개수만으로**: 8개 초과 낮음 · 5~8 보통 · 3~4 높음 · 3 미만 매우 높음 | 모델 수 + 모델 간 편차 + 성격 + 데이터 충실도 (리서치는 시나리오 분산 + 확신도 + 옵션 비중 + 경과일) |
| 데이터 | S&P Global Market Intelligence | Yahoo 재무제표·컨센서스, SEC XBRL·공시 원문, FRED |

아래 §1~§7 은 **기계적 기준선**(리서치의 출발점이자 교차검증)과 공통 계산 코어의 명세다.

## 1. 데이터 (전부 무료)

| 항목 | 소스 | 용도 |
|---|---|---|
| 연간 4년 + 분기 5~6개 재무제표 | Yahoo (`yfinance`) | TTM 실적, 마진·성장 이력, 재무상태 |
| 매출·EPS 컨센서스 (당해·차기 회계연도) | Yahoo | 1~2년차 성장률, 선행 EPS |
| 동종업계 구성 종목 | Yahoo Industry → 시가총액 로그 거리 가까운 순 10개 | peer 멀티플·베타·마진·성장 |
| 10년+ 연간 매출·영업이익·EPS·DPS | SEC EDGAR XBRL `companyfacts` | 경기순환 판별, 미드사이클 마진, 배당 성장 |
| 10년물 국채(DGS10) · AAA 회사채(DAAA) | FRED | 무위험금리, 그레이엄 공식 |

- **스냅샷/TTL**: 재무는 분기마다만 바뀐다. `state/fundamentals/{T}.json` 을 3~5일(종목별 지터) 재사용하고, 저장해 둔 다음 실적일이
  지나면 즉시 갱신한다. peer 프로필은 `_peers.json` 에 5일 공유 캐시. Yahoo 호출 제한(429)으로 프로필이 비면 스냅샷을 저장하지 않고
  이전 스냅샷을 쓴다.
- **TTM** = 최근 4개 분기 합(유량) + 최신 분기 잔액(저량). 분기가 부족하면 최근 연간.
- 통화가 다르면(ADR) 재무 통화 → 거래 통화로 환산. 결측은 `None` — 값을 만들어 내지 않는다.

### 파생 지표에서 처리하는 함정
| 문제 | 처리 |
|---|---|
| 컨센서스 매출 정의 ≠ 보고 매출 (예: 거래소 순매출) | 컨센서스의 '전년 실적' 대비 비율로 보고 기준에 맞춘 뒤 성장률만 사용 |
| 회계연도 중간 시점 | FY0·FY1 컨센서스를 NTM 으로 환산 (연중 성장은 기하급수로 배분 — 균등 분할은 고성장주를 과대추정) |
| 컨센서스가 이미 끝난 회계연도를 가리킴 | 한 해 밀어 적용 |
| GAAP EPS 에 일회성·영업외 손익 | 핵심 EPS = (영업이익 − 이자) × (1−세율) ÷ 주식수 와 25% 이상 다르면 핵심 EPS 를 이익 기준으로 |
| 적자 연도가 섞인 유효세율 | 3년 전부 흑자일 때만 합산 비율 사용, 아니면 TTM, 그것도 없으면 21% |
| 인수 무형자산 상각 | 현금 유출이 없는 비용 → FCFF 에 가산(연 25% 소멸) + 성숙·순환·배당 유형은 목표 마진에 소멸분 반영 |
| 영업권이 큰 투하자본 | 유기적 재투자 효율(Sales-to-Capital)·증분 ROIC 는 **유형** 투하자본 기준 |

## 2. 성격 분류 (archetype)

위에서부터 순서대로 판정한다. `g1` = 선행 12개월 매출 성장률, `m` = TTM 영업이익률.

| 순서 | 유형 | 조건 |
|---|---|---|
| 1 | `BANK` 은행·대출형 금융 | 산업명에 bank / 부채비율 2.5배 초과 신용·모기지 금융 / 손익계산서에 영업이익 행 없음 |
| 2 | `INSURANCE` | 산업명에 insurance |
| 3 | `REIT` | 부동산 섹터 + 산업명이 REIT |
| 4 | `PRE_REVENUE` 초기 단계·컨셉주 | (`m` < −50% 그리고 P/S > 15) 또는 매출 < $50M |
| 5 | `CYCLICAL` (저점) | 이익 미창출 + 최근 5년 중 2년 이상 흑자 + (경기민감 업종 또는 마진 변동성 큼·저성장) |
| 6 | `HYPERGROWTH_UNPROFITABLE` 고성장 적자 | 이익 미창출 + `g1` ≥ 20% |
| 7 | `TURNAROUND` | 이익 미창출 + 그 외 |
| 8 | `CYCLICAL` | 흑자 + 경기민감 업종 (소재·에너지 섹터, 자동차·철강·구리·우라늄·해운·반도체장비 등) |
| 9 | `HIGH_GROWTH` 고성장 흑자 | `g1` ≥ 15% (또는 과거 CAGR ≥ 20% 이고 `g1` ≥ 12%) |
| 10 | `CYCLICAL` | 마진 표준편차 > 6%p 이고 장기 중앙값의 절반 초과 |
| 11 | `DIVIDEND_DEFENSIVE` | 유틸리티 섹터, 또는 배당수익률 ≥ 2.5% · 배당성향 ≥ 40% · `g1` < 8% |
| 12 | `MATURE_COMPOUNDER` 성숙·현금창출 | 나머지 |

'이익 창출' = `m` > 3% 이고 (순이익 > 0 또는 FCF > 0). 속성(traits)으로 경기민감·현금 소진·주식보상 과다·서사 프리미엄을 따로 표시한다.

### 성격별 모델 가중치 (적용 불가 모델은 빠지고 재정규화)

| 유형 | 주력 (1.0~0.8) | 보조 | 쓰지 않는 것과 이유 |
|---|---|---|---|
| 성숙·현금창출 | 5년 DCF(영구성장·EBITDA Exit), P/E, EV/EBITDA | 10년 DCF, EPV, DDM, 그레이엄, 린치 | — |
| 배당·방어 | DDM(다단계·안정), P/E, EV/EBITDA, 5년 DCF | EPV, 그레이엄 | — |
| 고성장 흑자 | 10년 DCF(영구성장·EBITDA Exit), 선행 P/E | 5년 DCF, EV/EBITDA, 린치, EV/Revenue | EPV(성장 0 가정)는 0.15 만 |
| 고성장 적자 | 10년 DCF(Revenue Exit·영구성장), EV/Revenue | P/S, 5년 Revenue Exit | 이익 멀티플·EPV·그레이엄 (이익 없음) |
| 초기 단계 | 10년 DCF(Revenue Exit), 선행 EV/Revenue | 10년 DCF, P/B(현금 하방) | 5년 모델 전부, 이익 기반 전부 |
| 경기순환 | 정상화 EV/EBITDA, 5년 DCF(미드사이클 마진) | EPV, 정상화 P/E, P/B | 당기 이익을 그대로 연장하는 방식 |
| 턴어라운드 | EV/Revenue, 10년 DCF | P/S, P/B, Revenue Exit | 이익 멀티플 |
| 은행·보험 | 초과이익(RIM), P/B(ROE 보정), P/E | DDM | FCFF DCF·EV 멀티플 (부채가 영업 원재료) |
| REIT | P/FFO, DDM | EV/EBITDA, P/B | FCFF DCF·P/E (감가상각 왜곡) |

## 3. 자본비용

```
자기자본비용 ke = rf + β × ERP + 규모 프리미엄
  rf   = 미 10년물 (FRED DGS10)
  ERP  = 4.5% (환경변수 SMA_ERP)
  β    = 0.5 × Blume 조정 회귀베타(0.67β + 0.33) + 0.5 × peer bottom-up 베타   [0.5 ~ 2.5]
         peer 무부채 베타 중앙값 = β ÷ (1 + (1−t)·D/E) → 자사 D/E 로 재부채화
  규모 = 시총 ≥$100B 0 · ≥$10B 0.5% · ≥$2B 1.0% · ≥$0.3B 1.75% · 그 미만 3.0%
타인자본비용 kd = rf + 합성등급 스프레드(이자보상배율 기준 0.6% ~ 14%)
WACC = E/V·ke + D/V·kd·(1−t)       (시가 기준; 부채는 리스 포함)
```

예측 기간 동안 할인율은 **성숙기 자본비용으로 수렴**한다(베타·규모 프리미엄이 5년 모델 25%, 10년 모델 50% 만큼 시장 평균으로).
고베타 성장주가 영원히 고베타로 할인되는 왜곡을 막는다. 영구성장률 `g∞ = clip(0.6 × rf, 2%, 3%)`.

## 4. 전망 엔진 (DCF 공통)

| 항목 | 방식 |
|---|---|
| 매출 1·2년차 | 컨센서스(NTM 환산). 없으면 과거 CAGR 60% + 최근 YoY 40% |
| 3년차 이후 | `g_t = g∞ + (g₂' − g∞) × 0.65^(t−2)` — 초과 성장률이 매년 65% 만 잔존(반감기 ≈ 1.6년). `g₂'` 는 50% 초과분의 30% 만 인정 |
| 영업이익률 (흑자) | 현재 → 목표로 3~5년 선형 수렴. 목표: 성숙=최근 60%+5년 중앙값 40% / 고성장=현재+영업 레버리지(peer 상위 25% 방향, +8%p 한도) / 순환=장기 중앙값 |
| 영업이익률 (적자) | `m_t = m* − (m* − m₀) × (매출₀/매출_t) × √(1 − t/N)` — 손실은 고정비 성격이라 매출에 비례하지 않는다. 목표 `m*` = 흑자 peer 중앙값의 80%(실행 리스크), 매출총이익률의 40% 이내 |
| 세금 | 유효세율 → max(유효, 21%) 로 수렴. 예측 기간 중 발생한 결손금은 이월 공제 |
| 재투자 | `ΔRevenue ÷ Sales-to-Capital` (자사 유형자본 기준 50% + 업종·peer 50%) |
| 잔존가치(영구성장) | `FCFF_{N+1} = NOPAT × (1 − g∞/ROIC∞)`, `ROIC∞ = WACC∞ + min(초과수익의 절반, 8%)`, `TV = FCFF_{N+1} ÷ (WACC∞ − g∞)` |
| 잔존가치(EBITDA Exit) | `EBITDA_N ×` [peer 중앙값 · 자사 현재(peer 1.5배 한도) · 성숙기 이론값] 가중평균 (10년 모델일수록 이론값 비중↑) |
| 잔존가치(Revenue Exit) | `Revenue_N ×` [peer EV/Sales(마진 보정) · 목표 마진 기반 이론값] 가중평균 |
| 주주가치 | EV − 부채 − 우선주 − 비지배지분 + 현금, × (1 − 자금조달 실패 확률), ÷ 희석 주식수 |
| 할인 | 기중(mid-year) 할인 |

자금조달 실패 확률: 영업적자 + FCF < 0 일 때 현금 여력(현금 ÷ 연간 소진) 1년 미만 25% · 2년 미만 15% · 3년 미만 8% · 그 외 4% (+부채 > 시총이면 5%p).
각 모델의 **보수/낙관** 값은 성장(±15%)·목표 마진(±10%)·할인율(∓0.75%p)·g∞(±0.5%p)·Exit 배수(±15%)를 동시에 한 단계 움직인 시나리오다.

## 5. 모델 카탈로그

| ID | 모델 | 핵심 | 적용 조건 |
|---|---|---|---|
| `dcf_growth_5y/10y` | DCF · 영구성장 | §4 | 비금융·비REIT, 목표 마진 > 0 (초기 단계는 10년만) |
| `dcf_ebitda_5y/10y` | DCF · EBITDA Exit | §4 | + 예측 말 EBITDA > 0, 배수 근거 존재 |
| `dcf_revenue_5y/10y` | DCF · Revenue Exit | §4 | 비금융·비REIT |
| `epv` | 수익력 가치 | 정상화 영업이익 × (1−t) ÷ WACC − 순부채 (성장 0, 하방 기준선) | 정상화 이익 > 0, 이익 창출 유형 |
| `ddm_stable` | DDM 안정성장 | `D₁ ÷ (ke − g)` | 배당성향 40~115% |
| `ddm_multi` | DDM 다단계 | 5년 이익성장 수렴 후 영구성장, 성숙기 배당성향 = `1 − g∞/ROE∞` | 배당성향 30~115% |
| `residual_income` | 초과이익(RIM) | `BV + Σ(ROE−ke)·BV` , 초과수익 10년 소멸 | 은행·보험 |
| `pe` | P/E 멀티플 | 선행 EPS × peer 선행 P/E (60%) + 후행 핵심 EPS × peer 후행 P/E (40%) | EPS > 0 |
| `ev_ebitda` | EV/EBITDA | TTM(순환은 정상화) EBITDA × peer 배수 | EBITDA > 0 |
| `ev_rev` | EV/Revenue | 매출 × peer 배수 (초기 단계는 2년 뒤 매출을 ke 로 할인) | peer ≥ 3 |
| `ps` | P/S | 주당매출 × peer 배수 | peer ≥ 3 |
| `pb` | P/B (ROE 보정) | 주당순자산 × peer 배수(ROE 차이 보정), 금융은 이론 P/B `(ROE−g)/(ke−g)` 평균 | 순자산 > 0 |
| `p_ffo` | P/FFO | 주당 AFFO(≈FFO×0.85) × 이론 배수 | REIT |
| `lynch` | 피터 린치 | 공정 P/E = 5년 이익성장률 + 배당수익률 (6~35배) | 이익성장 ≥ 8% |
| `graham` | 그레이엄 | `EPS × (8.5 + 2g) × 4.4 ÷ AAA 수익률` | EPS > 0 |

**peer 멀티플 보정**: `적용 배수 = peer 중앙값 × exp(b·Δ성장 + c·Δ마진)`, 0.6~1.8배 한도. 보수/낙관 = peer 25/75 분위.
(EV/Revenue 는 마진 비율로 직접 보정.) peer 가 5개 미만이거나 섹터로 보충했으면 신뢰도 감점.

### 검증 체크 → 신뢰도(rel)
| 체크 | 실패 시 |
|---|---|
| 잔존가치가 기업가치의 85% 초과 | ×0.75 |
| Exit 배수가 내포한 영구성장률 > rf + 1% | ×0.70 |
| 유효 peer < 5 | ×0.70 |
| peer 를 섹터로 보충 | ×0.80 |
| 배당성향 > 90% | ×0.70 |
| 산출 가치 ≤ 0 | 모델 제외 |

## 6. 통합 · 불확실성 · 판정

```
w_i  = 성격별 기본 가중치 × rel_i
       모델 간 가중 중앙값에서 3배 이상 벗어나면 w_i × 0.25
fair = 0.5·가중평균 + 0.5·가중중앙값        (변동계수 > 35% 이면 0.25 / 0.75)
low  = min(Σ w·low_i , 가중 25분위),  high = max(Σ w·high_i , 가중 75분위)
```

**불확실성 점수** (100 에서 차감): 모델 수(9개 미만 −10, 5개 미만 −25, 3개 미만 −45) · 모델 간 변동계수 ×70 (최대 −35) ·
성격(초기 단계 −30, 고성장 적자/턴어라운드 −20, 고성장 흑자 −15, 순환 −12) · 영업적자 −12 · DCF 보수~낙관 폭 과다 −6 ·
컨센서스 없음 −8 · peer 5개 미만 −8 · 실적 3년 미만 −8 · 잔존가치 비중 80% 초과 −5 · 내재가치 vs 상대가치 1.6배 이상 괴리 −6.
→ 78 이상 `낮음` · 58 이상 `보통` · 38 이상 `높음` · 그 미만 `매우 높음`.

**판정**: 불확실성이 클수록 밴드가 넓다 — 낮음 ±10% · 보통 ±15% · 높음 ±25% · 매우 높음 ±35%.
적정가가 현재가보다 밴드 이상 높으면 `저평가`, 밴드의 2.5배 이상이면 `크게 저평가` (고평가도 대칭).
적정가와 현재가가 3배 이상 벌어지면 `model_gap` 을 세우고 "모델로 설명되지 않는 가격"으로 표시한다 — 이때는 적정가 수치보다 역DCF 가 핵심이다.

## 7. 진단

- **역DCF**: 현재가를 정당화하는 향후 5년 매출 CAGR 을 이분법으로 역산(이후 5년은 g∞ 로 수렴, 나머지는 기본 가정).
  성장으로 설명되지 않으면 목표 영업이익률을 역산하고, 그것도 60% 를 넘으면 "현 재무·컨센서스 밖의 요인이 가격을 지배"로 판정한다.
- **몬테카를로** (기본 4,000회, 시드 = 티커 CRC32 → 결정적): 성장(컨센서스 분산 반영)·목표 마진·할인율·g∞·재투자 효율·Exit 배수를
  동시에 흔들어 P10/P50/P90 과 `적정가 > 현재가` 확률을 낸다. DCF 입력의 불확실성만 반영한 분포다(통합 적정가와 다른 값).
- **민감도**: 할인율 ±1%p × 영구성장률 ±1%p 격자.

## 8. 출력

- `reports/valuation/{T}.json` — 발행 수치 (SMA 가 읽는 유일한 접점; 스키마는 `docs/SCHEMA_V3.md` 의 `valuation`).
- `reports/tickers/{T}/valuation.html` — 상세: 리서치(논지·시나리오·옵션·사업·성과·계획·뉴스·출처) → 기계적 교차검증 → 가정 → 역DCF·분포·민감도 → peer.
- `state/valuation/research/{T}.json` — 리서치 원본 (재계산·이력).
- SMA: 리포트 JSON `valuation` 키, Markdown Key Metrics, 3-Layer 리포트 브리핑 카드, 대시보드 `적정가 (괴리)` 열, 종목 페이지 카드·가격 차트의 적정가 선.
  SMA 는 계산하지 않는다 — 과거 세션 재실행(7일 초과)에는 붙이지 않으며 `SMA_VALUATION=0` 으로 끌 수 있다.

## 9. 한계 (출력에도 명시)

- **기계적 기준선**은 재무제표와 컨센서스에 없는 것(사업 계획, 신사업 옵션가치, 규제·소송, 경영진 변화)을 반영하지 못한다 — 그래서 발행값은 리서치 기반이다.
- **리서치**도 판단이다: 시나리오 확률과 옵션가치는 증거에 근거한 추정이며, 출처와 가정을 전부 노출해 반박 가능하게 둔다.
- 과거 이월결손금, 비영업자산(지분투자·보유 암호화폐 등), 전환증권 희석은 단순화했다.
- ERP·규모 프리미엄·합성등급 스프레드·섹터 기본값은 근사 상수다(`valuation.py` 상단, 환경변수로 조정).
- 금리가 높은 국면에서는 내재가치 계열(DCF·DDM·EPV)이 시장 멀티플 계열보다 구조적으로 낮게 나온다. 두 계열의 평균을 따로 표시하는 이유다.
- 투자 권유가 아니다.
