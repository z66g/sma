토큰 만드는 법
  • Fine-grained PAT 생성 — Repository access: Only select repositories → z66g/sma
  • Permissions: Contents: Read and write, Actions: Read and write, 만료일 설정 (저장소 전체 권한을 주는 Classic PAT 은 권장하지 않음)
  • 토큰은 이 브라우저의 localStorage 에만 저장되고, 저장소에 커밋되거나 GitHub 외의 곳으로 전송되지 않습니다.
관심종목 — 화~토 오전 자동 수급 분석
적정가 분석 — 관심종목에 넣기 전에
수급 분석 — 한 종목 즉시
도움말
  • 관심종목 — 화~토 오전(KST)에 직전 미국 정규장 세션을 자동 분석합니다(휴장일 건너뜀). 리서치가 없는 종목을 추가하면 적정가 조사도 바로 시작됩니다. 제거할 때 적정가가 있으면 검토 종목으로 옮겨집니다.
  • 적정가 분석 — 티커를 검토 종목에 넣고 약 2분 뒤 분석 세션이 시작됩니다. 신규 조사는 보통 20~40분, 재분석은 10~20분 걸리며 끝나면 새로고침했을 때 표에 반영됩니다. 검토 종목은 매일 수급 분석을 하지 않고, 분석 후 4주까지만 매주 주가·금리를 반영합니다. 채팅 세션에서 "티커 분석해줘"라고 해도 같은 분석이 됩니다.
  • 수급 분석 — 관심종목 여부와 상관없이 직전 세션의 3-Layer 리포트를 한 번 만듭니다(1~3분).
  • 표 — 종목 열은 가로로 스크롤해도 고정됩니다. 열 제목을 누르면 정렬하고, 한 번 더 누르면 반대로 정렬합니다.
